# AgentBridge Launch

**SKU #1:** Sell a production MCP gateway for a customer's API in days, not 6–12 weeks of DIY.

## Positioning

- **Problem:** Auth, schemas, allowlists, deploy, health, client config — weeks of calendar; agents stay blind.
- **Offer:** Fixed-path delivery of an HTTP MCP bridge off a proven live stack.
- **Not:** Manus reseller, unmetered key sharing, or legal advice product.

## Lead capture flow

1. Landing form collects name, email, company, package, API needs.
2. Client-side opens prefilled GitHub issue (no server-side secret required).
3. Operator replies on issue within 24h; track on ops issue board.

## Sales narrative (10 components)

Auth gate → tool catalogue → first-class tools → allowlisted proxy → upstream key injection → health plane → Vercel deploy → research hooks → client pack → repeatable delivery path.

## What delivery includes

- Deployed HTTPS MCP + health
- Tool catalogue + docs
- Client MCP JSON
- Encrypted secrets on Vercel
- 30-day fix window for gateway bugs

## Rules

- BYO customer API keys; never sell raw access to the operator's Manus key.
- Cap long Manus tasks (credits cost; heavy tasks burn margin).
- Prefer public, transparent lead trail over silent forms without backup.
